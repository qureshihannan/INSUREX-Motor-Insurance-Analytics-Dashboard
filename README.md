# INSUREX – Motor Insurance Analytics Dashboard

## Project Overview
INSUREX is an interactive Power BI dashboard designed to analyze motor insurance policies, premiums, and claims. It helps users explore claim patterns, regional performance, and insurance business trends.

## Objectives
- Analyze total premiums and sum insured.
- Track claim amounts and claim status.
- Understand regional and policy-level claim patterns.
- Identify trends that can support business decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Dashboard Features
- KPI cards for key insurance metrics
- Interactive filters and slicers
- Regional analysis
- Policy and claims analysis
- Time-based trend analysis
- Business insights and recommendations

## Project Files
- `.pbix` file: Power BI dashboard
- PNG files: Dashboard screenshots
